## 🚀 Running the Projects

1. Clone the repository:

```bash
git clone https://github.com/pranithbitla/Agentic-AI.git
```

2. Move into the repository:

```bash
cd Agentic-AI
```

3. Open the Python projects folder:

```bash
cd python-projects
```

4. Run any project, for example:

```bash
python ATM.py
```
