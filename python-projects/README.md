# Python Foundation Projects

This folder contains small Python projects created while strengthening programming fundamentals. They are intentionally simple and focus on core concepts before moving into larger AI applications such as CareerPilot AI.

## Projects

| File | What it demonstrates |
|---|---|
| `atm_simulator.py` | Loops, conditionals, transaction state, lists, and user input |
| `movie_recommender.py` | Lists, branching, dates, and interactive CLI flow |
| `chat_analyzer.py` | Menu-driven application, input validation, and modular Python |
| `chat_utils.py` | Reusable functions for chat/message analysis |

## Run a project

From the repository root:

```bash
cd python-projects
python atm_simulator.py
```

For the chat analyzer:

```bash
python chat_analyzer.py
```

Enter chat messages in this format:

```text
User: message text
```

## Learning Focus

These projects practice:

- Variables and data types
- Conditions and loops
- Functions
- Lists, sets, and dictionaries
- String processing
- Exception handling
- Imports and basic module separation
- Command-line user interaction

For the more advanced AI engineering project in this repository, see [`../careerpilot-ai/`](../careerpilot-ai/).
